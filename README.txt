SHIVA KARKI — PORTFOLIO V2
===========================

This is a complete static portfolio website designed to showcase:
- Your profile photo
- Detailed personal information
- Graphic design skills
- Documentation and MS Office skills
- Real portfolio projects
- Image gallery
- YouTube tutorials
- Downloadable CV
- Contact/social links

FOLDER STRUCTURE
----------------
index.html
style.css
script.js
assets/
  images/
  videos/
  documents/

BEFORE PUBLISHING
-----------------
1. Add your profile photo:
   assets/images/profile.jpg

2. Add your real project images:
   project-1.jpg through project-6.jpg

3. Add gallery images:
   gallery-1.jpg through gallery-4.jpg

4. Put your CV here:
   assets/documents/Shiva-Karki-CV.pdf

5. Open index.html in a text editor and replace:
   your.email@example.com
   +977XXXXXXXXXX

6. Add YouTube video IDs in the tutorial cards.
   Example:
   data-video="dQw4w9WgXcQ"

7. Replace the YouTube channel link.

IMPORTANT
---------
The site intentionally contains placeholders so you can insert your own
photo and work. No external JavaScript library is required.

PUBLISHING
----------
You can publish the whole folder using GitHub Pages, Netlify, Vercel,
or another static hosting provider. Upload ALL files while preserving
the folder structure.

The homepage file must remain named:
index.html
